# 保留地形转折点的贴地路径

用户授权：先采用当前场景适用的小改法，计算并保留坡脚、坡顶处的路径交点；维持现有 RViz 操作，由用户自行视觉测试。不提交，不修改真实点云。

实施范围以 path_optimizer.cpp 为主，不改变拓扑分区和 A* 搜索策略，不引入新的完整规划算法。依据网格实际相邻面的平面变化识别地形折边，计算引导路径与折边的交点；不得硬编码演示坐标或坡道高度。候选路径由原引导点的地面投影与必要的折边交点组成；全路径仍须通过原贴地、通道、连通、坡度、曲率和净空检查。简化不能删除必要地形折点。原有密集贴地流程保留为复杂/歧义情形的后备。

1. 保存当前已索引优化的源码和静态库，使用现有 timing harness 强制重编记录相同输入的基线。此前更早的 2.68 秒基线另行保留。
2. 先补回归并确认旧实现不能满足精确坡脚/坡顶交点要求；覆盖正向、反向，以及含多个转折且平地冗余点能简化的场景。使用几何断言，不依赖机器耗时阈值。
3. 增加轻量折边路径候选，避免常见平面组合场景先密集恢复高度再大量捷径搜索。歧义时回退既有安全流程，保持 5 毫米容差不变。
4. 修复前次复核发现的索引锐角候选遗漏与 timing harness 缓存不识别链接库的问题，分别补有意义的回归或可复现验证。
5. Release 构建、规划器回归、同输入多次计时与独立安全校验。复审新增差异。
6. 安装库、重新链接 ROS planner_node、刷新实际演示数据及离线测试，复核路径确实含地形交点。用户自行重启 launch 测试。

允许修改：规划器优化实现及必要测试；演示计时工具、导出数据/使用说明。保留工作区其他已有修改和旧报告。报告放 log/crease_preserving_path/。
