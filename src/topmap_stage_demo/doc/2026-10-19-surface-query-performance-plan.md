# 贴地路径查询性能优化

用户已授权按前一轮提出的局部查询、空间索引和复用结果方案优化；保持当前工作区，保留所有已有修改，不提交。

目标：减少当前约 2.7 秒的路径优化时间，不调整 5 毫米贴地容差、采样密度、通道顺序、可放置性、曲率或安全规则。

1. 保存修改前生产源码和演示规划结果。用同一 Release 构建、地图归档、配置、起终点测量重复规划的优化耗时和总耗时，排除地图构建/加载；校验实际返回路径。
2. 复用现有 MeshGrid 为垂向高度查询提供完整候选集，保持重叠层、边界、相同距离的确定性选择以及连通性检查。局部邻居查询只可作为保持原选择语义的加速；不能漏掉候选。
3. 让密集贴地结果与原引导顶点的贴地结果共享一次连续采样，避免重复遍历。限制在 path_optimizer.cpp 内，不重构其他算法。
4. 运行已有坡道、反向、孔洞、分离面、通道和曲率回归；索引边界或多层行为缺覆盖时才增加有实际意义的回归。性能用重复测量对比，不增加机器相关的 CI 超时断言。
5. 同样输入重复测量修改后时间，比较路径/安全检查结果。独立复审增量差异。
6. 安装更新的静态库并重新链接 ROS planner_node，刷新演示数据，运行演示离线测试。保持 launch 和选点交互。用户自行进行 RViz 视觉测试。

预期修改：src/topmap_planner/src/path_optimizer.cpp；必要的规划器回归测试；src/topmap_stage_demo/tools 的可重用离线计时工具及简短使用说明；演示导出数据。性能报告放 log/，不覆盖之前的报告。
